# 知识库型 Skill 规范

本文档规定包含参考图、参考文件、模板、资料集合或知识索引的知识库型 Skill 的设计、目录和维护要求。创建或修改此类 Skill 时，必须先读取并遵循本文档。

## 1. 适用范围

当 Skill 需要长期复用一组外部资料，或需要根据资料目录、索引和引用关系检索内容时，视为知识库型 Skill。仅在对话中临时读取单个文件，不构成知识库型 Skill。

## 2. 目录边界

- 所有知识库资源必须位于该 Skill 的专用目录内。
- `SKILL.md` 负责说明能力、触发条件、工作流程和资源加载规则。
- `references/` 存放按需阅读的文字资料、结构化知识和索引说明。
- `assets/` 存放参考图、模板、字体及其他二进制或不可直接作为指令阅读的资源。
- `scripts/` 只存放处理、校验、转换或索引生成脚本。
- `evals/` 只存放评估用例和评估结果。
- 不得把知识库资源写入 Skill 目录之外，也不得把临时文件、用户隐私或凭据纳入知识库。

## 3. 参考图规范

- 参考图必须有稳定、可读、可排序的文件名，并使用与内容一致的扩展名。
- 参考图按主题、用途或处理阶段分目录；目录层级应保持浅且稳定。
- 每张图必须在索引中有对应记录，至少包含路径、用途、主题或标签、来源状态和说明。
- SKILL.md 只描述如何选择和读取参考图，不直接嵌入图片内容或大段图像说明。
- 处理多张图片时，必须依据索引或输入顺序明确图片身份，不能仅依赖模型猜测文件名。

## 4. 参考文件规范

- 参考文件按主题或用途组织，优先使用可检索的 Markdown、纯文本或结构化格式。
- 大型资料应拆分为可独立加载的文件，避免单个文件承担无关主题。
- 每个参考文件应有清晰标题、稳定路径和可识别的主题边界。
- 原始文件、转换文件和摘要文件必须区分存放，并在索引中标明关系。
- SKILL.md 不复制参考资料正文，只定义何时读取、读取哪些文件以及如何使用结果。

## 5. 目录索引规范

- 知识库必须有一个稳定的根索引文件，索引文件位于该 Skill 的知识资源目录内。
- 索引记录应至少包含：资源路径、资源类型、主题或标签、用途、来源或版本状态。
- 路径必须使用相对于 Skill 根目录的路径，不能依赖本机绝对路径。
- 索引必须能从条目定位到实际资源；删除或移动资源时必须同步更新索引。
- 资源数量较多时，可以增加主题索引或分目录索引，但必须保留从根索引进入的路径。
- 不得仅维护一个无法验证的资源名称清单；索引必须支持选择、定位和核验。

## 6. 加载与引用规则

- 默认只加载与当前请求相关的索引和资源，不要一次性读取整个知识库。
- 先读取索引，再根据主题、标签、文件类型或任务阶段选择资源。
- 使用资源后，输出中应说明使用了哪些资源；需要精确依据时，引用相对路径和相关章节或记录。
- 找不到匹配资源时，明确说明未命中，不得把未确认内容当作知识库结论。
- 资源之间存在依赖时，按索引定义的顺序加载，并保留来源关系。

## 7. 更新与质量检查

- 每次新增、删除、移动或替换资源后，都必须更新索引。
- 资源和索引应保持可解析、路径有效、命名一致和无重复记录。
- 创建前规划至少包含一次索引完整性检查和一次资源引用检查。
- 测试用例应覆盖：能够命中资源、资源不存在、索引缺失或资源路径失效等情况。
- 未经用户确认，不得擅自下载、复制、改写或扩充知识库内容。
