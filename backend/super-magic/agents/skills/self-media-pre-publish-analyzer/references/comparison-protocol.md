# Comparable Content Protocol

Use this protocol whenever web search is available. Comparable content informs diagnosis, but it must not replace file evidence from the current post.

## Search Plan

Run 2-4 focused searches. Combine:

- Platform keyword: `小红书`, `公众号`, `微信公众号`, or the platform name.
- Topic keyword: the article's title topic, category, product, audience pain, or solution.
- Goal keyword:
  - `IP增长`: 人设, 信任, 个人品牌, 专家号, 系列内容
  - `产品转化`: 转化, 咨询, 成交, 案例, 卖点, CTA
  - `爆文流量`: 爆款, 标题, 封面, 搜索, 互动, 转发
- Format keyword:
  - Xiaohongshu/Rednote: 图文, 笔记, 封面, 标题, 卡片
  - WeChat: 长文, 排版, 摘要, 封面, 完读, 转发

## Comparable Sample Selection

Prefer 3-5 samples or references:

- 1-2 directly comparable same-topic pieces.
- 1-2 same-platform operational references about cover/title/layout/publishing fields.
- 1 adjacent high-performing format if same-topic samples are weak.

Reject or down-rank samples when:

- The topic, audience, or platform is materially different.
- The source is mainly selling a tool with no observable examples.
- The page is outdated, inaccessible, or only repeats generic advice.
- The content cannot be inspected beyond a title snippet.

## Source Handling

- State whether a source is a comparable content sample, operational reference, or platform policy.
- Treat Canva, KAWO, Yiban, creator blogs, and marketing articles as operational references only.
- Do not call third-party tips official platform rules.
- If search results are weak, say so and lower confidence instead of inventing competitor patterns.
- Use concise source summaries; do not copy long excerpts.

## Comparison Table

Include a compact comparison in the report when enough information is available:

| Aspect | Comparable pattern | Current work | Optimization implication |
| --- | --- | --- | --- |
| Opening promise | What top samples promise first | Current cover/title/lead behavior | What to change |
| Audience/pain | Who the samples target | Current audience clarity | How to sharpen |
| Evidence/payoff | Cases, lists, frameworks, proof | Current evidence | What proof to add |
| Format rhythm | Card/section rhythm | Current sequence | What to move/cut |
| CTA/interaction | Comment/save/follow/consult trigger | Current CTA | How to improve |

## Confidence Rules

Use `high` confidence when current files are readable and comparable samples are clearly relevant.

Use `medium` confidence when current files are readable but external samples are adjacent rather than direct.

Use `low` confidence when article/card files are missing, search fails, or only generic references are available.

Never let strong external references compensate for unreadable current work. Missing files remain a blocker for precise scoring.
