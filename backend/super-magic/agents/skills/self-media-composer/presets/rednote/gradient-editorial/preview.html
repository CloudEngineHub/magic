02 / 05 核心方法

如何让 Codex 自动蒸馏工作流？

总体思想是让 Codex 回顾你的会话、Memories 和 Chronicle，识别其中的模式，复用已有内容，并且只创建最小但有用的技能、子代理或自动化。

只有当候选项满足以下条件时才采取行动：至少发生过两次，或明显很可能再次发生且重复成本较高。

输入稳定、流程可重复，并且有明确产出或停止条件
能明显提升速度、质量、一致性或可靠性
尚未被现有内容充分覆盖

03 / 05 操作步骤

按优先顺序使用可用证据

1

回顾 Codex 会话和任务摘要

找到最近 30 天内重复出现的任务模式

2

分析 Memories 和 Rollout 摘要

发现跨会话重复出现的模式

3

选择最小且合适的形式

Skill 用于可复用流程，Subagent 用于需要独立推理的任务

💡 关键原则

优先复用或扩展已有内容，避免重复创建。Chronicle 仅用于发现，重要细节尽可能回到相关源系统中确认。
