02 / 05 Core method

How can Codex distill workflows automatically?

The core idea is to have Codex review your conversations, Memories, and Chronicle, identify patterns, reuse existing content, and create only the smallest useful skill, subagent, or automation.

Act only when a candidate meets these conditions: it happened at least twice, or is clearly likely to recur with meaningful repeated cost.

Inputs are stable, the process is repeatable, and outputs or stopping conditions are clear
It clearly improves speed, quality, consistency, or reliability
It is not already covered well enough by existing content

03 / 05 Steps

Use available evidence in priority order

1

Review Codex conversations and task summaries

Find task patterns repeated in the last 30 days

2

Analyze Memories and rollout summaries

Find patterns recurring across sessions

3

Choose the smallest suitable form

Use a skill for reusable workflows and a subagent for tasks that need independent reasoning

Key principle

Prefer reusing or extending existing content to avoid duplicate creation. Use Chronicle only for discovery, and confirm important details in the relevant source system whenever possible.
