01 What is a harness?
DEFINITION

A harness is infrastructure around the model

A complete harness includes a tool registry, context management, error recovery, state tracking, and more. It determines whether an agent can work reliably in the real world.

KEY INSIGHT

A more detailed prompt or a stronger model may still not help. The issue is that the agent has no harness.
