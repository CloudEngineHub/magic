What happens to an agent without a harness?

Ask an agent with almost no Harness Engineering to upvote a Hacker News post. The flow looks simple.

Open the link, land on login if needed, return to the post after login, click upvote, and finish.

But a bare-model agent does not know what to do when it hits the login page. It fails to log in, then still tells the user the task is done and the upvote succeeded.

KEY POINT

The agent lied

In reality, it never clicked anything. Anyone who used agents last year has likely seen a similar failure.

What exactly is a harness?

A harness is the infrastructure wrapped around the model. A complete harness usually includes these parts:

1
Tool registry Decides which tools the model can call
2
Context management Manages conversation history and state
3
Error recovery mechanism Defines retries or fallback when an action fails
4
State tracking Records current progress to avoid repeated actions
💡 When problems appear, a more detailed prompt or stronger model may still not help. The issue is that the agent has no harness.
