# File Formats & Examples

## Root `magic.project.js`

JSONP file at the project root. Always generated by `create_self_media_project`; never overwritten with `write_file`. Edit only the inner `posts` array via `edit_file`, keeping the JSONP wrapper intact.

```js
window.magicProjectConfig = {
  version: "1.0.0",
  type: "self-media",
  name: "<project folder name>",
  "self-media": {
    rednote: {
      posts: [
        {
          id: "ai-bill",
          name: "AI Billing Breakdown",
          entry: "posts/ai-bill/post.json",
        },
      ],
    },
    "wechat-official-accounts": {
      posts: [
        {
          id: "feature-launch",
          name: "Super Magic PPT Export Is Live",
          entry: "posts/feature-launch/post.json",
        },
      ],
    },
  },
};
window.magicProjectConfigure(window.magicProjectConfig);
```

Each platform lives under its own key inside `self-media`. The key itself (`rednote`, `instagram`, …) identifies the platform; its value carries the `posts` array.

## Per-Post `post.json`

Plain JSON (not JSONP). Produced by `create_self_media_post`; edit with `edit_file` for subsequent changes.

### rednote / instagram (card-based)

```json
{
  "id": "ai-bill",
  "meta": {
    "title": "AI Billing Breakdown",
    "subtitle": "Cost, structure, and optimization",
    "tags": "#AI #Billing",
    "author": "@magic",
    "feedTitle": "AI billing, explained in one post",
    "feedLikes": "18k",
    "commentCount": "128",
    "comments": [{ "name": "Alice", "text": "Very clear structure" }]
  },
  "cards": ["cards/01.html", "cards/02.html"]
}
```

### wechat-official-accounts (article-based)

```json
{
  "id": "feature-launch",
  "meta": {
    "title": "Super Magic PPT Export Is Live",
    "subtitle": "Turn any webpage into an editable PPT",
    "tags": "#PPT #AI #Productivity",
    "author": "@SuperMagic",
    "feedTitle": "Turn any webpage into an editable PPT — element-level fidelity",
    "feedLikes": "23.8w",
    "commentCount": "3.2k",
    "time": "4 minutes ago"
  },
  "article": "feature-launch.html",
  "heroCover": "assets/cover-hero.jpg",
  "thumbnailCover": "assets/cover-square.jpg"
}
```

## Path Rules (non-negotiable)

1. Paths in `post.json.cards` are relative to the current post folder, not the project root.
2. `entry` in root `posts[]` must be `posts/<post-id>/post.json`.
3. Cards reference their own assets via relative paths: `assets/<name>.png` for post-local, `../../shared/<name>.png` for project-shared.
4. Card filenames must not carry a numeric prefix (for example, do not use `01_cover.html`). Ordering is controlled by `post.json.cards`, not by filename.
5. For `wechat-official-accounts`: `article`, `heroCover`, `thumbnailCover` paths are all relative to the post folder. Do **not** fill both `cards` and `article` in the same `post.json`.
