# AI 卡片使用指南

## 功能概述

AI 卡片是一种定时自动生成的可视化信息卡片。系统会根据你设定的 Prompt 指令和时间计划，由 AI 自动抓取数据并生成精美的 HTML 卡片页面，支持历史版本回溯和手动立即执行。

---

## 使用步骤

### 第一步：创建 AI 卡片

1. 在 Super Magic 项目中打开一个 AI 卡片文件夹
2. 首次打开时，系统会自动跳转到**配置面板**（因为尚无配置）

### 第二步：填写配置

在配置面板中需要填写以下信息：

| 字段 | 说明 | 必填 |
|------|------|------|
| **卡片名称** | 给你的卡片起个名字，如"每日热点追踪" | ✅ |
| **模板** | 选择卡片样式模板 | 否 |
| **Prompt 指令** | 告诉 AI 需要分析什么数据、生成什么内容 | ✅ |

**可选模板类型：**

- **热点追踪器** (hotspot-tracker) — 追踪热门话题
- **每日摘要** (daily-digest) — 每日信息汇总
- **分析面板** (analytics-panel) — 数据分析看板
- **自定义** (custom) — 使用卡片目录中自己的 `template.html`

> **⚠️ 重要提示：所有模板均支持用户二次修改。** 你可以在卡片目录中直接编辑 `template.html` 文件，调整布局、配色、数据展示方式等。AI 在每次生成卡片时会读取最新的模板文件作为参考，因此你的修改会在下一次生成时生效。

### 第三步：配置高级选项（可选）

展开"高级设置"区域可以配置：

- **定时计划** — 设置卡片的自动更新频率（如每天早上 8 点）
- **语言模型** — 选择用于生成内容的 AI 模型
- **图片模型** — 选择用于生成图片的模型
- **视频模型** — 选择用于生成视频的模型
- **启用/关闭** — 控制定时任务是否激活

### 第四步：保存配置

点击"保存"按钮，系统会：

- 创建或更新定时任务
- 返回卡片仪表盘视图

### 第五步：查看卡片仪表盘

保存后进入仪表盘界面，你可以看到：

- **卡片名称和描述** — 顶部显示
- **最新版本** — 网格中展示当前最新生成的卡片缩略图
- **历史版本** — 之前生成的卡片，按时间倒序排列
- **最后更新时间** — 右上角显示

### 第六步：手动立即执行

如果不想等定时触发，可以点击仪表盘顶部的 **▶ 立即运行** 按钮：

1. 点击按钮后，系统会立即触发一次卡片生成任务
2. 生成成功后，会自动跳转到对应的会话主题查看执行过程
3. 新生成的卡片会出现在仪表盘中

### 第七步：查看卡片详情

点击仪表盘中的任意卡片缩略图，进入**详情视图**：

- 全屏展示卡片 HTML 内容（通过 iframe 渲染）
- 点击左上角 **← 返回** 回到仪表盘

### 第八步：查看历史版本

点击仪表盘中带"历史版本"标签的卡片，可以查看之前某次生成的结果。历史文件按 `YYYY-MM-DD_HH-mm.html` 格式命名。

### 第九步：修改配置

在仪表盘右上角点击 **⚙ 设置** 按钮，重新进入配置面板修改任何参数。

## 使用场景示例

### 场景一：每日行业热点追踪

**目标：** 每天早上自动生成一张行业热点信息卡片，快速了解当天最新动态。

**配置示例：**

- 卡片名称：`AI 行业每日热点`
- 模板：热点追踪器 (hotspot-tracker)
- Prompt：`请搜索并整理今天 AI 和大模型领域的 Top 10 热点新闻，包含标题、摘要、来源和热度评分。重点关注 OpenAI、Google、Meta 等主要厂商的动态。`
- 定时计划：每天 08:00

**效果：** 每天早上 8 点自动生成一张包含热点排名、摘要和来源链接的可视化卡片。

---

### 场景二：竞品数据监控面板

**目标：** 定期跟踪竞品的公开数据变化，生成对比分析面板。

**配置示例：**

- 卡片名称：`竞品周度分析`
- 模板：分析面板 (analytics-panel)
- Prompt：`请搜索以下竞品的最新公开数据（用户量、融资动态、产品更新）：产品A、产品B、产品C。以对比表格和趋势图的形式呈现，标注本周重大变化。`
- 定时计划：每周一 09:00

**效果：** 每周一早上生成一张包含竞品数据对比的分析面板卡片。

---

### 场景三：个人知识摘要

**目标：** 每天汇总关注领域的最新内容，形成个人知识简报。

**配置示例：**

- 卡片名称：`前端技术日报`
- 模板：每日摘要 (daily-digest)
- Prompt：`请搜索今天 React、Next.js、TypeScript 相关的最新技术文章和 GitHub 热门项目，整理成 5-8 条精选内容，每条包含标题、一句话摘要和链接。`
- 定时计划：每天 18:00

**效果：** 每天下班前生成一张技术日报卡片，方便晚间阅读。

---

### 场景四：自定义模板 — 品牌周报

**目标：** 使用完全自定义的模板样式，生成符合公司品牌规范的周报卡片。

**配置示例：**

- 卡片名称：`市场部周报`
- 模板：自定义 (custom)
- Prompt：`请根据本周的市场活动数据，生成市场部周报。包含：本周活动概览、获客数据、转化漏斗、下周计划。数据展示要使用图表形式。`
- 定时计划：每周五 17:00

**关键步骤：** 在卡片目录中编辑 `template.html`，植入公司品牌色、Logo 和固定布局结构。AI 会基于你的模板填充最新数据。

---

## 关于模板的二次修改

> **所有模板（包括预设模板和自定义模板）都支持用户自由修改。**

AI 在生成卡片时的工作流程为：

1. 读取卡片目录下的 `template.html` 获取布局结构
2. 根据 Prompt 获取和分析最新数据
3. 基于模板结构 + 新数据生成完整 HTML 页面

因此，你可以随时修改 `template.html` 来：

- **调整布局** — 改变信息区块的排列方式
- **更换配色** — 使用自己的品牌色或偏好风格
- **增减区域** — 添加或删除数据展示模块
- **自定义样式** — 修改字体、间距、圆角等 CSS 样式
- **嵌入固定内容** — 如公司 Logo、固定标语等

修改后，下一次卡片生成时 AI 会自动采用最新的模板结构。已生成的历史卡片不受影响。

## 卡片目录结构

AI 卡片在文件系统中的结构如下：

```
卡片目录/
├── magic.project.js    # 卡片配置文件（自动管理）
├── template.html       # 卡片模板（可自由编辑）
├── latest.html         # 最新生成的卡片
└── history/            # 历史版本
    ├── 2026-05-24_08-00.html
    ├── 2026-05-23_08-00.html
    └── ...
```

---

## 注意事项

- 配置中**卡片名称**和 **Prompt 指令**为必填项，未填写时无法保存
- 定时计划未配置时，卡片不会自动更新，但可以手动运行
- 每次生成新卡片时，旧的 `latest.html` 会自动归档到 `history/` 目录
- "立即运行"执行期间按钮会显示加载状态，请勿重复点击
- 修改 `template.html` 后无需重新保存配置，下次生成时自动生效
